### What I've built

**DevArena** — real-time competitive programming platform
Production-grade pnpm monorepo with 6+ shared workspace packages. Sandboxed
code execution via BullMQ workers and Docker, isolated from the API layer so
untrusted submissions can't touch it and can scale independently. Express +
Socket.IO backend, Prisma/PostgreSQL, Redis, multi-stage Docker builds behind
NGINX, Vitest and CI throughout.

**[Smart Substitution & Product Recommendation Engine](https://smart-reco-frontend.vercel.app/)** — MERN + Gemini
Ranks the top-5 in-stock substitutes for any product using a weighted scoring
model across category, price similarity, and rating. A MongoDB caching layer
cut redundant Gemini calls by ~70% and dropped repeat-request latency from
seconds to milliseconds. The AI "reason" explainer falls back to a template on
API failure, so response coverage stays at 100%. JWT auth, cart/wishlist, and
Stripe checkout on top.
→ **[Live demo](https://smart-reco-frontend.vercel.app/)**

**RAG Document Q&A Pipeline** — Python, LangChain, ChromaDB
Ingests documents, splits them into overlapping chunks, and indexes embeddings
in a vector store for semantic search. Recursive character splitting, encoding
auto-detection, and chunk-level source tracking so every answer stays citable
and grounded in the source text.
